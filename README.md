# Insanos Moto Fest

Estrutura normal do site:

- `index.html` — página principal
- `assets/flyer.png` — flyer principal; pode ser substituído por outro PNG mantendo este nome
- `assets/` — demais imagens, fontes e scripts usados pelo site

Para trocar o flyer, substitua `assets/flyer.png` por outra imagem PNG e mantenha o mesmo nome.
